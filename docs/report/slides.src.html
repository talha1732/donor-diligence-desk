How it works

Four AI agents between code that handles every number

A fixed pipeline, not a free-roaming boss agent: predictable cost, no loops, every stage testable. gpt-6-luna reads and judges; Python does the arithmetic and the checking.

  • Code computes all 17 ratios, so prompts carry short facts, not raw filings

Safety

Charity websites are untrusted input, and the defenses are tested

  • $0.10 per run and $2 per day kill switches; tool and request caps
  • Unreadable sites and missing data are "not scored", never 0

What's next

From a working prototype to the December giving season

Limits today

  • Free IRS data lacks program-spending share and runs about a year behind
  • Impact evidence is only what a charity publishes; some sites block automated readers
  • Scores use a documented rubric, a hypothesis rather than a standard
